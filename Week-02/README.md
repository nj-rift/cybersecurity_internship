# Week 02 – Footprinting and Network Scanning

Organization: NetworkWalks

## Activities Completed

### 1. Kali Linux – Domain Footprinting
- WHOIS Lookup
- Website Technology Detection using WhatWeb
- DNS Lookup using Nslookup
- HTTP Header Inspection using cURL
- WAF Detection using Wafw00f
- DNS Enumeration attempt using DNSRecon

### 2. Windows – Network Scanning
- IP Configuration using ipconfig
- Network Host Discovery using Nmap
- Ping Scan using Zenmap
- Network Topology Visualization

## Learning Outcomes
- Understood domain footprinting.
- Learned website technology identification.
- Practised DNS and HTTP inspection.
- Understood IP addressing and subnetting.
- Performed basic local network host discovery.

## Observations
- Zenmap identified two responsive hosts.
- DNSRecon encountered DNS timeout errors.
- The scan was limited to host discovery, not port scanning.

## Tools Used
Kali Linux, WHOIS, WhatWeb, Nslookup, cURL,
Wafw00f, DNSRecon, Nmap and Zenmap.
